# 💝 Özel Günler

Önemli günlerine geri sayım yapan ve anılarını saklayan basit bir web uygulaması.
Yıldönümleri, doğum günleri, sınavlar... hepsini tek yerde takip et.

## ✨ Özellikler

- ➕ Başlık, tarih ve isteğe bağlı not ile özel gün ekleme
- ⏳ Her gün için otomatik geri sayım (kaç gün kaldı / geçti)
- 📅 Günleri yaklaşana göre otomatik sıralama
- 💾 Veriler tarayıcıda saklanır (localStorage) — sayfa kapansa da kaybolmaz
- 🗑️ Tek tıkla silme

## 🛠️ Kullanılan Teknolojiler

- HTML5
- CSS3
- Vanilla JavaScript (localStorage)

## 🚀 Çalıştırma

`index.html` dosyasını tarayıcıda aç. Kurulum veya internet gerektirmez.
